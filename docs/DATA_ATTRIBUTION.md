# 数据来源与署名

本项目知识图谱种子数据来自：

- **面向家庭常见疾病的知识图谱**
- 贡献者：东南大学（王之畅、罗卓彦、朱启鹏、朱浩嘉、王湘源、吴天星 等，以 OpenKG 页面为准）
- 发布平台：[OpenKG](http://openkg.cn/)
- 数据集页：<http://openkg.cn/dataset/medicalgraph>
- 许可：[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)

使用约束：

1. 保留署名与许可声明（产品 UI 页脚、文档、衍生数据发布页）。
2. 对图谱做修改或再分发时，按相同许可共享。
3. 不把该数据宣传为医院官方知识库或诊疗依据。
4. 不抓取寻医百科等站点来「补全」本图谱。

手写 FAQ（`data/faq/`，板块一添加）为项目原创导诊对照，用于别名与评测，不替代图谱事实。
